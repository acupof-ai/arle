# GLM-5.2-FP8 (`glm_moe_dsa`) → DSv4 V32 port — full-chain design

**Status**: design locked, review-before-validate. Config parser landed (`ffc0b0bf`).
**Target**: GLM-5.2-FP8 on 8×H20, truncated layers for bring-up (full 755.6 GB does
not fit — reference SGLang truncates to `num_hidden_layers=30`; full = offload follow-up).

## Verdict

GLM-5.2 = DeepSeek-V3.2-DSA family. It rides the **already-vendored FlashMLA V32 path**
(d_qk=576 = 512 NoPE + 64 RoPE = GLM's `kv_lora_rank=512`+`qk_rope_head_dim=64`), the DSA
interleaved `freqs_cis`, DeepGEMM FP8 MoE, EP=8 DeepEP, and the sigmoid/noaux router.
**No new kernel.** New code = wire V32 (our wiring hard-codes MODEL1), load-time `kv_b`
absorption, and four structural branches (dense-MLP / hyper-connection-absent / plain-o_proj /
FP8 scale naming) + one mode (`SparseIndexed`).

## The MLA-shape gap (the crux)

DSv4 checkpoint is **pre-absorbed MODEL1**: no `kv_b` anywhere, `head_dim=512` IS the absorbed
latent, hard-asserts NoPE=448/RoPE=64/d_qk=512, 584 B/token pack
(`dsv4.rs:52,70`, `attention.rs:6192`, *"a different shape needs a new pack kernel"*).
GLM ships **standard non-absorbed** MLA at the V32 shape (kv_lora 512 + rope 64 = 576) with a
real `kv_b_proj`. Bridge = **absorb `kv_b` at load** (standard SGLang/vLLM MLA prep): fold
W_UK into `q_b_proj` (query attends in 512-latent) and W_UV into `o_proj` (latent→v→hidden),
producing the absorbed wq_b + o path V32 expects. Then select V32 (`model_type_int=0`),
not MODEL1.

## Structural gaps + fix (file:line)

1. **Attention mode.** `v4.rs:417-440` has only SlidingWindow/CompressedSparse/HybridCompressed;
   `has_indexer()` true only for CompressedSparse (which also `has_compressor()`). GLM = indexer
   only, no compressor → add 4th variant `SparseIndexed` (indexer ✓, compressor ✗).
2. **IndexerShape ↔ compressor couple.** `v4.rs:267 indexer_shape` hard `.expect`s a compressor;
   struct field `v4.rs:476 compressor: DeepSeekV4CompressorShape` non-optional → make `Option`,
   gate on `has_indexer()`. Ripples to `DeepSeekV4IndexerTensorNames.compressor` (`v4.rs:663`) and
   `Dsv4Indexer.compressor` (`dsv4.rs:102`) + `load_dsv4_indexer` (`loader.rs:3157`).
3. **Pack/decode shape.** Parameterize the MODEL1 asserts (`dsv4.rs:70`, `attention.rs:6192`) to
   accept V32 (NoPE=512); wire/confirm the V32 FP8 pack (the shim documents V32 — likely a 2nd
   instantiation, not new code). `model_type_int` 0=V32 / 1=MODEL1 (`shim.cu:59`).
4. **Dense MLP layers.** GLM `first_k_dense_replace=3`; DSv4 runs MoE every layer
   (`dsv4.rs:3013,3389`). Add a dense-FFN branch for `!is_sparse_layer` (glm.rs helper exists).
5. **Hyper-connections absent.** DSv4 loads `hc_attn/hc_ffn/hc_head` unconditionally
   (`dsv4.rs:1084-1095`), `stream_dim=hidden*hc_mult`. GLM has none → hc-bypass when `hc_mult==1`
   (identity mixers, `stream_dim==hidden`).
6. **Plain o_proj.** GLM has no o_lora/o_groups; DSv4 always wo_a→wo_b (`attention.rs:8598`).
   Add a single-GEMM o_proj branch (`mla_oproj` + `load_dsv4_attention` `loader.rs:3077`).
7. **FP8 scale naming.** DSv4 expects `<p>.scale` E8M0 (`loader.rs:2589,2595`); GLM ships
   `<name>.weight_scale_inv` F32 → add a GLM scale-name + F32 path.
8. **Tensor names.** Make the deepseek-spec name builders dialect-aware: emit GLM HF names
   (`model.layers.N.self_attn.{q_a_proj,kv_a_proj_with_mqa,kv_b_proj,o_proj,indexer.*}`,
   `mlp.gate.e_score_correction_bias`, `mlp.experts.E.{gate,up,down}_proj`, `mlp.shared_experts.*`,
   `model.embed_tokens.weight`, `lm_head.weight`, `model.norm.weight`) under a `Glm` flag. Loader
   resolves verbatim (`loader.rs:2356`), unchanged. MTP: checkpoint ships none → `num_nextn=0`.

## Tranche order (typecheck-first)

- **A — deepseek-spec + infer-cuda match-arm updates** (Mac: `cargo test -p deepseek-spec`;
  `cargo check -p infer-api --no-default-features --features cuda,no-cuda --lib`):
  new config fields (`kv_lora_rank`/`qk_nope_head_dim`/`v_head_dim`/output-proj enum, Option/default
  so DSv4 parses byte-unchanged); `SparseIndexed` mode + decouple IndexerShape; add the ripple
  match arms in `attention.rs` (5398/939) + `dsv4.rs`; `GlmMoeDsaConfig::into_deepseek_v4`
  (V32/576, plain-o, hc_mult=1, num_nextn=0) + unit tests.
- **B — dispatch** (Mac typecheck): `classify_cuda_model` (`loaded.rs:108`) glm_moe_dsa → kind,
  **before** the experts→Qwen35 branch (`loaded.rs:130`); `into_deepseek_v4()` call site at
  `dsv4.rs:1037`.
- **C — loader** (GPU build): GLM tensor-name dialect; load-time `kv_b` absorption; plain-o load;
  F32 `weight_scale_inv` path; dense-MLP weights; hc-absent.
- **D — forward** (GPU build): V32 select; SparseIndexed branch (indexer over full latent, no
  compressor, full-latent pack); dense-FFN; hc-bypass; plain-o.
- **E — validate (later, no rush)**: truncated GLM-5.2 on 8×H20, load→forward→`needle_gate`
  (x3 same-config vs envelope; self-consistency, NOT byte-identity). Full-model offload separate.
